Use when

A security code has expired, has been entered incorrectly too many times, or has been resent too many times.

Suggested page language

  • Your security code has expired — Security codes expire after 15 minutes. Ask us to send a new security code, then enter it on the next page. Primary action: Send a new security code.
  • You entered the wrong security code too many times — You need to get a new security code and try again.
  • You entered the wrong security code too many times (locked out) — You will not be able to sign in for 2 hours. Wait 2 hours, then go back to the form you were trying to use and try again.
  • You've asked to resend the security code too many times — You will not be able to sign in for 2 hours. Wait 2 hours, then go back to the form you were trying to use and try again.

Keep the channel specific: use email when creating or signing in, and phone when recovering a sign-in.
