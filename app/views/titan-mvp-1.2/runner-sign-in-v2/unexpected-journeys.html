{{ journeyDocs.journeyPath([ { text: "Check your email or phone" }, { text: "Enter the 6 digit security code" }, { text: "Security code problem", unexpected: true } ]) }}

Use when

A security code has expired, has been entered incorrectly too many times, or has been resent too many times.

Suggested page language

  • Your security code has expired - send a new security code.
  • You entered the wrong security code too many times - link to get a new code, or show a 2 hour lockout.
  • You asked to resend the security code too many times - show a 2 hour lockout.

Keep the channel specific: use email when creating or signing in, and phone when recovering a sign-in.
