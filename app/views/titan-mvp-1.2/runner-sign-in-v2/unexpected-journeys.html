Unexpected journeys

Use this page to review what should happen when someone cannot continue through the expected sign-in, recovery or checking journeys.

{% set createEmailInUseHtml %}
{{ journeyPath([ { text: "Start page" }, { text: "Why you need to sign in" }, { text: "Enter your email address" }, { text: "You already have a sign-in for this form", unexpected: true } ]) }}

Use when

Someone tries to create a sign-in with an email address already connected to a saved form.

Suggested page language

You already have a sign-in for this form

Sign in using this email address to continue your form.

Primary action: Sign in. Secondary link: Use a different email address.

{% endset %} {% set signInNotFoundHtml %}
{{ journeyPath([ { text: "Start page" }, { text: "Sign in" }, { text: "Enter your email address to sign in to your form" }, { text: "We cannot find a sign-in for that email address", unexpected: true } ]) }}

Use when

Someone enters an email address that is not connected to a form sign-in.

Suggested page language

We cannot find a sign-in for that email address

Check the email address or create a sign-in if you have not used this form before.

Primary action: Try again. Secondary link: Create a sign-in.

{% endset %} {% set mobileNumberHtml %}
{{ journeyPath([ { text: "Create a sign-in" }, { text: "Enter your email address" }, { text: "Enter your mobile phone number" }, { text: "You need a UK mobile phone number to create a sign-in", unexpected: true } ]) }}

Use when

Someone cannot provide a UK mobile number. In this design, the number is used only to recover access to a form sign-in.

Suggested page language

You need a UK mobile phone number to create a sign-in

We use this number to send a security code if you need to recover your sign-in.

Primary action: Enter a UK mobile phone number. Secondary link: Continue without creating a sign-in, if the form allows it.

{% endset %} {% set securityCodeHtml %}
{{ journeyPath([ { text: "Check your email or phone" }, { text: "Enter the 6 digit security code" }, { text: "Security code problem", unexpected: true } ]) }}

Use when

A security code has expired, has been entered incorrectly too many times, or has been resent too many times.

Suggested page language

  • Your security code has expired - send a new security code.
  • You entered the wrong security code too many times - ask the user to wait before trying again.
  • You asked us to send too many security codes - ask the user to wait before requesting another code.

Keep the channel specific: use email when creating or signing in, and phone when recovering a sign-in.

{% endset %} {% set recoverHtml %}
{{ journeyPath([ { text: "I've forgotten my email address" }, { text: "Text a security code to your mobile" }, { text: "Enter your new email address" }, { text: "We cannot recover your sign-in online", unexpected: true } ]) }}

Use when

Someone cannot use the mobile number they gave when they created their sign-in, or cannot confirm a new email address.

Suggested page language

We cannot recover your sign-in online

You can start a new form or contact the service if you need access to a saved form.

Primary action: Start a new form. Secondary link: Contact the service.

{% endset %} {% set linkExpiredHtml %}
{{ journeyPath([ { text: "Save and exit email or checker invite email" }, { text: "Open link" }, { text: "This link has expired", unexpected: true } ]) }}

Use when

A save-and-exit link or checker invite link is outside its allowed time window.

Suggested page language

  • Your link to return to this form has expired - sign in from the form start page.
  • This review link has expired - ask the applicant to send a new invite.
{% endset %} {% set technicalErrorsHtml %}
{{ journeyPath([ { text: "Any runner sign-in v2 page" }, { text: "Service unavailable or page not found", unexpected: true } ]) }}

Use when

A system error happens at any point in the journey. These pages are not tied to a specific step.

Suggested page language

  • Sorry, the service is unavailable - tell the user to try again later.
  • Page not found - link back to the form start page.
  • Sorry, there is a problem with the service - use when the route is recoverable but the action failed.
