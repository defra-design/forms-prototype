Copy page user journey

Visual flow with live prototype screenshots. Persona: Chris (form designer). Critical path: confirmation (conditions warning) → land on copy → rename.

1. Page overview — discover Copy page

Entry

User action

  • Opens page overview
  • Clicks Copy page

Thought

  • “Is this the right control?”

2. Confirmation — review what will be copied

Moment of truth

User sees

  • Proposed name with (copy)
  • Question count
  • Page conditions will not be copied

Decision

  • Copy page, or Cancel back to overview
Cancel Return to original page overview — no change
Copy page System clones questions, omits page conditions, inserts after source

3. New page overview — success and rename

Aha moment

User sees

  • Success: Page copied
  • Prompt to rename
  • Lands on the new page, not the original

Next

  • Rename the page
  • Edit questions if needed
  • Rebuild conditions manually if required
